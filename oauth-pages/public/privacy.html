Privacy Policy

Nest AC Monitor · Last updated 27 August 2026

Nest AC Monitor is a personal application with a single user: its owner. It is not distributed, not offered as a service, and has no other users. This policy describes how it handles data.

Data accessed

With the owner's explicit Google authorization, the application reads the following from the owner's own Nest thermostat, using the Google Smart Device Management API:

  • Ambient temperature
  • Ambient humidity
  • Heating and cooling status, and thermostat mode
  • Temperature setpoint
  • Device connectivity status

It requests only the sdm.service scope, and it reads. It sends no commands to the thermostat.

How the data is used

Readings are used to detect when the thermostat reports that it is cooling while the measured temperature is not falling, which indicates an air conditioning fault. When that occurs, the application sends a notification to the owner's own phone.

How the data is stored

All readings are stored in a database file on the owner's own computer. Google account credentials are stored on that same computer, in a file restricted to the owner's user account. Nothing is stored on this website or on any server.

Data sharing

No data is sold, shared, transferred, or disclosed to any third party. The application communicates with two services only: Google's Smart Device Management API, to read the thermostat, and a push notification service chosen by the owner, to deliver alerts to the owner's own phone.

Retention and deletion

Readings are retained on the owner's computer for 90 days and then deleted automatically. The owner may delete the database, revoke the application's access, or both, at any time. Access can be revoked at myaccount.google.com/permissions, which immediately and permanently ends the application's ability to read any data.

Contact

This application has one user, who is also its author. Enquiries may be directed to the owner of this domain.
